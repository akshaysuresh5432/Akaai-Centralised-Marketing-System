# Akaai Spaces desk

A light operating desk for **Akaai Spaces**.

- **Projects** — current work, and the campaigns running under each
- **Companies** — who we onboarded; open one for deliverables, timeline, publish dates, invoice dates
- **Calendar** — reminders for everyone (publish in blue, invoice in gold)
- **Video** — editor downloads footage, uploads the cut, posting downloads it

Little sample data. Add your own with **Add**.

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:43211](http://localhost:43211).
